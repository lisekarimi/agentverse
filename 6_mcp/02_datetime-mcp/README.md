# DateTime MCP

**Here are 5 challenging test cases to validate this MCP server:**

1. **"I want to book an appointment the Friday after Thanksgiving 2025"**
2. **"Is the last Monday of January 2026 available?"**
3. **"Can I schedule something on New Year's Day next year?"**
4. **"What's the first available appointment day after Christmas this year?"**
5. **"I need an appointment 3 weeks and 2 days from today - is that a weekend?"**


For Windows users, run in WSL terminal:

```bash
cd 6_mcp/02_datetime-mcp/
uv run use_date_mcp.py
```
